# Сайт сервиса помощи студентам

Многостраничный сайт на **Next.js 16 (App Router) + TypeScript + CSS Modules + GSAP**.
Заявки из формы уходят в Telegram-бот.

---

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать токен бота и chat_id
npm run dev                  # http://localhost:3000
```

Прод:

```bash
npm run build
npm start
```

## Подключение Telegram-бота

1. Создать бота у [@BotFather](https://t.me/BotFather) → получить `TELEGRAM_BOT_TOKEN`.
2. Узнать `TELEGRAM_CHAT_ID`: написать боту любое сообщение и открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — нужен `chat.id`.
   Для группы: добавить бота в группу и взять id вида `-100...`.
   Можно указать несколько получателей через запятую.
3. Вписать значения в `.env.local`.

Пока переменные не заданы, форма работает, заявка пишется в лог сервера
(`[lead] ...`) и пользователь всё равно видит страницу «Заявка отправлена» —
ничего не ломается на этапе разработки.

## Что где менять (без залезания в вёрстку)

| Файл | Что внутри |
|---|---|
| `src/content/site.ts` | название, контакты (Telegram/VK/WhatsApp), меню, тексты кнопок, буллеты доверия |
| `src/content/services.ts` | карточки услуг + список видов работ в форме |
| `src/content/steps.ts` | четыре шага «как всё происходит» |
| `src/content/advantages.ts` | блок «почему выбирают нас» |
| `src/content/reviews.ts` | отзывы (можно добавлять скриншоты: `image: '/reviews/1.png'`) |
| `src/content/faq.ts` | вопросы и ответы (блок на главной) |
| `src/content/collage.ts` | предметы в коллаже на первом экране: позиция, размер, наклон |
| `src/app/globals.css` | палитра, радиусы, типографика — всё через CSS-переменные |

Название (`site.name`, сейчас `VI`) и контакты-заглушки (`@username`, `vk.com/club`, номер) — меняются в `site.ts`.

## Анимации (GSAP + ScrollTrigger)

- мягкое анимированное свечение на первом экране (`components/home/GlowField.tsx`) — медленный дрейф пятен + лёгкая реакция на курсор;
- коллаж предметов с рамкой выделения: появление, «дыхание», параллакс от мыши;
- заголовок первого экрана выезжает из маски по словам;
- появление секций при скролле (`hooks/useReveal.ts`) — одна логика на весь сайт;
- прогресс-линия в блоке «четыре шага» рисуется по мере прокрутки;
- бесконечная бегущая строка с видами работ;
- плавные переходы между шагами формы и анимация прогресса.

Всё уважает `prefers-reduced-motion`: при включённой настройке анимации отключаются,
контент остаётся видимым. Для пользователей без JS есть `noscript`-фолбэк.

## Форма заявки

- три шага: вид работы → детали → контакты;
- обязательные поля с понятными ошибками, валидация контакта под выбранный мессенджер;
- вложение до 15 МБ (методичка/задание) уходит в бот отдельным документом;
- черновик хранится в `localStorage` — заявка не теряется при перезагрузке;
- антиспам: скрытое поле-ловушка, проверка времени заполнения, лимит 5 заявок с IP за 10 минут;
- дата и время заявки добавляются в сообщение (МСК).

## Деплой на Vercel

1. Залить проект в GitHub-репозиторий (приватный — норм).
2. На vercel.com: **Add New → Project → Import** этот репозиторий. Next.js определяется сам,
   команды сборки менять не нужно.
3. В **Environment Variables** добавить `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`,
   `NEXT_PUBLIC_SITE_URL` (для Production и Preview) → **Deploy**.
4. Домен: **Settings → Domains → Add**. У регистратора для корня — запись `A` на `76.76.21.21`,
   для `www` — `CNAME` на `cname.vercel-dns.com`. После подключения обновить
   `NEXT_PUBLIC_SITE_URL` и передеплоить.

`vercel.json` в корне держит функции во Франкфурте (`fra1`) — ближайший регион к РФ.
Если не нужно, файл можно удалить.

**Лимит вложения.** У serverless-функции Vercel тело запроса не больше 4.5 МБ, поэтому
`MAX_FILE_MB` и `NEXT_PUBLIC_MAX_FILE_MB` стоят на 4. На своём сервере (VPS + `pm2`
или Docker, Timeweb/Selectel) лимита нет — поднимайте обе переменные до 15–20.

Любой другой хостинг с Node 20+ тоже подойдёт: `npm ci && npm run build && npm start`.

## Коллаж на первом экране

Предметы нарисованы вектором (`src/components/home/Objects.tsx`). Чтобы поставить свои
картинки, положите PNG без фона в `public/stickers/` и укажите путь в `src/content/collage.ts`:

```ts
{ id: 'hoodie', object: 'laptop', image: '/stickers/hoodie.png', x: 46, y: 22, width: 28, rotate: -2, float: -9 }
```

Позиция, размер и наклон берутся оттуда же, рамка выделения и анимации остаются.

## Палитра и шрифты

Холст `#f2f2f2`, поверхности `#ffffff` и `#ededed`, текст чистый чёрный,
единственный акцент — красный `#df030d` (реплики, ховеры, активные состояния).
Всё задано переменными в `src/app/globals.css` — поменять акцент можно одной строкой.

Везде один гротеск — **Onest** (кириллица, подключён через `next/font`, самохостится
при сборке, внешних запросов в рантайме нет).

На референсе стоит **Gilroy** — платный шрифт, его файлов нет в открытом доступе,
поэтому в проект он не положен. Если лицензия у вас есть, подмена делается за минуту:
положите `Gilroy-Medium.woff2`, `Gilroy-SemiBold.woff2`, `Gilroy-ExtraBold.woff2`
в `public/fonts/` и замените в `src/app/layout.tsx`:

```ts
import localFont from 'next/font/local';

const display = localFont({
  src: [
    { path: '../../public/fonts/Gilroy-Medium.woff2', weight: '500', style: 'normal' },
    { path: '../../public/fonts/Gilroy-SemiBold.woff2', weight: '600', style: 'normal' },
    { path: '../../public/fonts/Gilroy-ExtraBold.woff2', weight: '800', style: 'normal' },
  ],
  variable: '--font-display',
  display: 'swap',
});
```

`--font-sans` можно завести так же (или оставить Onest для текста).
